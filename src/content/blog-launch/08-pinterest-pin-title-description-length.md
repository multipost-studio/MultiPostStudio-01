Pinterest description length is up to 800 characters per pin, and a pin title can be up to 100 characters, according to Pinterest's API specification as of 2026. Alt text, which describes the image for people who cannot see it, can be up to 500 characters. These are maximums, and most pins need far less.

## Key takeaways

- Pinterest description length can reach 800 characters in the Pinterest API, and a pin title can be up to 100 characters.
- Alt text for a pin can be up to 500 characters, and it describes the image for people who use screen readers.
- Pinterest works partly as a visual search engine, so titles and descriptions should state what the pin shows and who it is for in plain, searchable words.
- The limits are ceilings: a clear title and a description of a few sentences are usually enough.
- A pin has three text fields with different jobs, so write each one on purpose rather than repeating the same sentence three times.

## What are the Pinterest description length and title limits?

A Pinterest pin title can be up to 100 characters, and a description up to 800 characters, according to the Pinterest API v5 specification for creating pins. Alt text can be up to 500 characters. These figures come from the API documentation that publishing tools follow, and they apply to image pins and video pins.

Here is the whole picture as of 2026:

| Field | Maximum | What it is for |
|---|---|---|
| Pin title | 100 characters | Names the pin in a few words |
| Pin description | 800 characters | Explains what the pin shows and where it leads |
| Alt text | 500 characters | Describes the image for screen readers |

One caveat is worth stating plainly. These numbers are the API limits. Pinterest's own website and app show their own fields while you type, and what you see there may differ in places. If a tool and the Pinterest app give you different counts, trust the one that blocks you and check Pinterest's current help pages.

## How should you use each field?

Each field has a separate job, and the best pins make each one count. Writing three different texts takes a minute longer than copying one, and it gives you three chances to describe the pin in the words people use.

### How do you write a pin title?

A good pin title names the subject and the benefit in a short line. Think of it as the headline someone sees while scrolling.

1. **Lead with the main subject.** "Small Balcony Herb Garden Ideas" beats "My Latest Post".
2. **Name the benefit or format.** Words like "ideas", "checklist", "recipe" or "step by step" tell people what they will get.
3. **Keep it well under 100.** A title that fits on a line or two is easier to read than one that fills the allowance.
4. **Avoid all caps and filler.** Plain wording reads better and is easier to match to a search.

### How do you write a pin description?

A pin description should say what the pin shows and what a person will find when they click. Use natural sentences, put the important words early, and add detail that is not in the image.

A simple structure:

1. One sentence that describes the pin and its main keyword.
2. One or two sentences on what the reader gets, such as a list, a method or a template.
3. A short call to action, such as "Save this for your next project" or "Read the full guide".

Most descriptions work well at a few sentences. The 800-character Pinterest description length leaves room for more, but length is not a goal. If you find yourself repeating the same keyword several times to fill space, cut the repetition.

### What goes in pin alt text?

Alt text describes the image literally and briefly, for example "A balcony with six small pots of basil, mint and parsley on a wooden shelf." Write it as if you were describing the image to someone on the phone. Do not stuff it with keywords. Its first job is accessibility, and a clear description helps everyone who cannot see the image.

## How does Pinterest SEO work for titles and descriptions?

Pinterest SEO means writing your pins so that the words match what people search for on Pinterest. People use the platform to look for ideas, so the words in your title, description and board names help the platform understand a pin's topic. Pinterest has not published a ranking formula, so no one outside Pinterest can promise a particular effect.

What you can do is make your pins easy to understand:

- **Use the phrase a searcher would type.** "Vegetarian meal prep for beginners" is more useful than "Yummy food".
- **Put the key phrase early** in both the title and the description.
- **Be consistent across the pin, the board and the page it links to.** The same topic in all three gives a clear signal.
- **Write for a person first.** If a sentence reads badly aloud, rewrite it.

You can find phrases by typing a topic into Pinterest's search bar and noting the suggestions that appear, then using the ones that honestly describe your pin.

## What are good Pinterest pin best practices for text?

A short checklist keeps pins consistent when you publish many of them:

1. **One topic per pin.** A pin that tries to cover three subjects is hard to title.
2. **A title that stands alone.** It should make sense without the image.
3. **A description that adds information.** Do not repeat the title word for word.
4. **Alt text on every image.** It takes seconds and helps accessibility.
5. **A destination that matches.** The page the pin links to should deliver what the pin promises.
6. **A different pin for a different angle.** If you promote the same article again, write a new title and description instead of reusing the old ones.

Reusing the same text on several pins for one page is easy to do and easy to avoid. A new angle gives you a new title and a new set of words.

## How do you plan Pinterest text alongside other platforms?

Pinterest descriptions are longer than a Threads post and shorter than a LinkedIn post, so a caption written for another platform rarely fits as it is. An Instagram caption can run to 2,200 characters, which would be cut hard to fit 800. A tweet-length line fits, but it may be too thin to describe the pin.

Treat the Pinterest text as its own piece of writing. Start from the topic and the reader, not from the caption you already have. Then check the title is under 100 and the description is under 800 before you schedule.
